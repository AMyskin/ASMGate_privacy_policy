Политика конфиденциальности GateByASM

Последнее обновление: 15.10.2026

Введение

GateByASM уважает вашу конфиденциальность. Эта политика конфиденциальности объясняет, какие данные могут обрабатываться при использовании приложения GateByASM (далее — «Приложение»), для каких целей они используются и как защищаются.

GateByASM предназначено для управления системами контроля доступа и воротами. Приложение позволяет управлять пользователями, предоставлять временный или ограниченный доступ, просматривать историю проходов и дистанционно открывать ворота через интернет.

Обрабатываемая информация

Данные пользователей системы доступа

В зависимости от настроек системы и способа идентификации пользователя в приложении могут использоваться:

  • номер телефона;
  • имя или никнейм пользователя;
  • номер участка или другое обозначение, позволяющее идентифицировать пользователя внутри системы доступа.

Эти данные необходимы для управления пользователями системы контроля доступа и позволяют определить, кому предоставлен доступ к воротам.

Пользователь может самостоятельно выбрать, какую информацию использовать для идентификации человека в системе. Фамилия пользователя не является обязательной.

Данные доступа к системе

Для подключения к системе управления воротами в настройках Приложения могут указываться данные, необходимые для авторизации и подключения к совместимому контроллеру.

Эти данные используются для установления соединения между Приложением и устройством управления воротами через интернет и выполнения предусмотренных системой функций.

История проходов

История проходов хранится на устройстве управления воротами и может быть получена Приложением для отображения пользователю.

Запись истории прохода может содержать:

  • номер телефона пользователя;
  • дату и время прохода.

История проходов используется исключительно для отображения событий системы контроля доступа и контроля использования ворот.

Данные подключения

Для работы с совместимым контроллером Приложение использует сетевые параметры, необходимые для подключения к устройству, включая его IP-адрес.

Подключение к контроллеру осуществляется напрямую через интернет. Приложение не использует собственный облачный сервер для передачи команд управления воротами между пользователем и контроллером.

Удалённое управление воротами

GateByASM позволяет дистанционно управлять совместимым устройством управления воротами.

При нажатии пользователем кнопки открытия ворот Приложение передаёт контроллеру соответствующую команду управления, например команду open.

Команда открытия не требует передачи разработчику содержимого команды или персональных данных пользователя. Соединение осуществляется непосредственно между Приложением и контроллером через интернет.

Push-уведомления

GateByASM может использовать push-уведомления для отображения статуса операций управления воротами.

Например, при выполнении команды открытия ворот через CarPlay Приложение может получить уведомление о результате операции и отобразить статус открытия ворот.

Для работы push-уведомлений могут использоваться системные сервисы Apple. Необходимые технические данные для доставки push-уведомлений обрабатываются соответствующей инфраструктурой Apple.

Доступ к контактам

GateByASM может запрашивать доступ к контактам устройства для удобства работы с пользователями системы контроля доступа.

Доступ к контактам может использоваться, например, для:

  • сопоставления номера телефона пользователя с контактом на устройстве;
  • получения имени контакта;
  • использования фотографии контакта при отображении пользователя в Приложении.

Доступ к контактам предоставляется пользователем отдельно посредством системного разрешения iOS. Без предоставления такого разрешения соответствующие функции, связанные с контактами, могут быть недоступны.

Аналитические данные

Для анализа работы Приложения и улучшения его качества мы используем Yandex AppMetrica.

С помощью AppMetrica может собираться техническая и статистическая информация, необходимая для анализа использования Приложения, включая:

  • модель устройства;
  • версию операционной системы;
  • версию Приложения;
  • информацию о сессиях;
  • информацию об использовании функций Приложения;
  • информацию о технических ошибках и сбоях.

Аналитические данные используются для анализа стабильности Приложения, выявления ошибок, улучшения существующих функций и разработки новых функций.

GateByASM не использует AppMetrica для хранения истории проходов пользователей ворот или для управления доступом к воротам.

Данные, которые мы не используем

GateByASM не требует предоставления разработчику следующих данных для обычной работы Приложения:

  • паролей от личных аккаунтов социальных сетей;
  • банковских данных;
  • данных о местоположении пользователя;
  • фотографий пользователя, загруженных специально для идентификации в приложении.

Приложение не использует геолокацию для определения местоположения пользователя.

Хранение данных

  • Данные, связанные с управлением пользователями и системой доступа, могут храниться на совместимом устройстве управления воротами.
  • История проходов хранится на устройстве управления воротами и содержит данные, необходимые для отображения событий доступа.
  • Настройки подключения, необходимые для работы Приложения, могут храниться локально на устройстве пользователя.
  • Данные, полученные из контактов, используются в рамках предоставленного пользователем разрешения iOS.
  • Аналитические данные обрабатываются инфраструктурой Yandex AppMetrica.

Использование данных

Обрабатываемая информация используется для следующих целей:

  • управления пользователями системы контроля доступа;
  • предоставления и изменения доступа пользователей;
  • создания временного или ограниченного гостевого доступа;
  • просмотра истории проходов;
  • удалённого управления воротами;
  • отображения статуса выполнения команд управления;
  • сопоставления пользователей с контактами устройства при наличии соответствующего разрешения;
  • анализа работы и улучшения Приложения.

Передача данных

Для выполнения своих основных функций GateByASM передаёт необходимые данные непосредственно между Приложением и совместимым устройством управления воротами через интернет.

Команды управления воротами, такие как команда открытия, передаются непосредственно контроллеру.

Разработчик Приложения не получает содержимое команд управления воротами в рамках обычной работы Приложения.

GateByASM не содержит рекламных SDK и не передаёт данные рекламным сетям для показа персонализированной рекламы.

Apple Push Notification service

Для доставки push-уведомлений GateByASM может использовать системную инфраструктуру Apple Push Notification service (APNs).

Push-уведомления используются для информирования пользователя о событиях и статусе операций, связанных с управлением воротами.

Безопасность

Мы принимаем разумные технические меры для защиты данных и предотвращения их несанкционированного использования.

  • Соединение между Приложением и контроллером осуществляется через интернет.
  • Доступ к функциям управления воротами требует указания необходимых параметров подключения и доступа в настройках Приложения.
  • Системные разрешения iOS используются для доступа к контактам и другим защищённым ресурсам устройства.
  • История проходов хранится на устройстве управления воротами и не используется для рекламного профилирования.

При этом ни один способ передачи или хранения данных через интернет не может гарантировать абсолютную безопасность. Пользователь должен обеспечивать конфиденциальность данных доступа к своей системе управления воротами.

Удаление данных

Пользователь может удалить Приложение со своего устройства.

Удаление Приложения удаляет локальные данные, хранящиеся непосредственно на устройстве пользователя, в соответствии с механизмами хранения iOS.

Удаление Приложения не удаляет данные, которые уже хранятся на устройстве управления воротами. Такие данные необходимо удалять средствами самой системы управления воротами.

Права пользователя

Пользователь имеет право:

  • отозвать предоставленный Приложению доступ к контактам через настройки iOS;
  • удалить Приложение и его локальные данные;
  • удалить или изменить пользователей и права доступа средствами системы управления воротами;
  • обратиться к разработчику с вопросами относительно обработки данных.

Изменения в политике конфиденциальности

Мы можем периодически обновлять настоящую политику конфиденциальности.

При внесении изменений новая версия политики будет опубликована на этой странице, а дата «Последнее обновление» будет изменена.
